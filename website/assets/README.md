## Required Images

### hero-screenshot.png
- **Size**: 1400×800px
- **Description**: Screenshot of Effortless CRM extension in Gmail showing:
  - Gmail inbox with sidebar open
  - CRM pipeline view visible
  - Deal cards in kanban layout
  - Voice assistant button visible

**How to create**:
1. Load the extension in Chrome
2. Open Gmail
3. Open a pipeline view
4. Take screenshot (Cmd/Ctrl + Shift + 4 or use browser dev tools)
5. Crop to 1400×800px
6. Save as `hero-screenshot.png`

## Image Optimization

Before deploying:
1. Compress images: Use TinyPNG or ImageOptim
2. Convert to WebP for better performance
3. Create 2x versions for retina displays
4. Add `loading="lazy"` attribute to img tags
